# Peluquería Admin 0.2.0-alpha.2

## Descargar e instalar Peluquería Admin

[Descargar el instalador público de Peluquería Admin 0.2.0-alpha.2](https://github.com/colombianitov2/peluqueria-admin/releases/download/v0.2.0-alpha.2/PeluqueriaAdmin-Setup-v0.2.0-alpha.2.exe)

Una instalación `0.2.0-alpha.1` también puede obtener esta versión desde
**Ajustes > Actualizaciones**, sin desinstalar ni ejecutar manualmente otro instalador.

## Cambios principales

- Tarifa diaria exacta de lunes a sábado; el domingo no cobra ni consume saldo.
- Historial de vigencias de tarifa, cargos diarios y asignaciones de silla.
- Pagos aplicados a los cargos más antiguos y consumo progresivo del saldo a favor.
- Aportes con operaciones separadas de alta, edición y eliminación, y efecto neto correcto en caja.
- Saldo disponible del local visible sin convertir financiación en ganancia.
- Detalles multilínea con altura automática en Movimientos del día.
- Logotipo K&V original en ejecutable, ventana, accesos directos, instalador y portable.
- Migración aditiva desde `0.2.0-alpha.1`, sin convertir cuotas semanales históricas.

## Compatibilidad y seguridad

Es una Versión preliminar pública para Windows x64. El instalador no está firmado digitalmente y
Windows puede mostrar SmartScreen. La base permanece fuera de la carpeta de la aplicación; el arranque crea una
copia previa cuando detecta una migración pendiente.
